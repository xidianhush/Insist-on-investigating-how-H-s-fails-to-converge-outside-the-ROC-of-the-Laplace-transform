拉普拉斯变换收敛域 (ROC) 可视化

双边拉普拉斯变换三种典型信号对比 — 拖动滑块观察积分窗口展开过程中 $X(s)$ 的收敛 / 振荡 / 发散行为

$X(s) = \dfrac{2a}{a^2-s^2}$  |  ROC: $-a < \operatorname{Re}(s) < a$（带状）

衰减系数 $a$1.0
积分窗口右端点 $T_{\text{right}}$（左端点固定 $-30$）0.0

3D 模-相图（Z轴 = 幅值，颜色 = 相角）

两个极点 $s = \pm a$（金色菱形），两条红色竖线为 ROC 边界 $\sigma = \pm a$。拖动 $T_{\text{right}}$ 从左到右：积分窗口从空 → 只含负时间部分 → 逐渐加入正时间部分 → 完整双边积分。两者收敛条件的交集就是带状 ROC。

双边信号的核心结论

● 负时间部分 $t<0$：$x(t)=e^{at}$

收敛条件 $\operatorname{Re}(s) < a$，对应极点 $s=a$ 左侧。

● 正时间部分 $t>0$：$x(t)=e^{-at}$

收敛条件 $\operatorname{Re}(s) > -a$，对应极点 $s=-a$ 右侧。

● ROC = 两部分收敛条件的交集

$-a < \sigma < a$ 是带状区域，带宽 $2a$，$a$ 越小 ROC 越窄。

● 两个极点决定系统模态

$s=a$ 对应负时间增长模态，$s=-a$ 对应正时间衰减模态。

$X(s) = \dfrac{1}{s+\alpha}$  |  ROC: $\operatorname{Re}(s) > -\alpha$（右半平面）

积分上限 $T$（$T<0$ 时积分区间落在 $t<0$，信号为 0）5.0
衰减系数 $\alpha$1.0

1. 3D 模-相图（Z轴 = 幅值，颜色 = 相角）

红色竖线 = ROC 边界 $\sigma = -\alpha$，金色菱形 = 极点。

2. 三点对比：ROC 内 / 边界 / ROC 外 — $|Z(s)|$ 随 $T$ 变化

3. ROC 边界振荡专题（$\sigma = -\alpha$）

$$|Z(s)| = \frac{2\left|\sin\left(\dfrac{\omega T}{2}\right)\right|}{|\omega|}$$ 振幅 $= \dfrac{2}{|\omega|}$，  周期 $= \dfrac{2\pi}{|\omega|}$，  永不收敛

核心结论

● 收敛 = 曲线贴平

ROC 内 $T$ 增大后 $|Z(s)|$ 趋于定值，极限存在。

● 振荡 = 相位不收敛

边界上模不爆炸，但相位持续旋转，极限不存在。

● 发散 = 指数爆炸

ROC 外幅值随 $T$ 指数增长，积分无意义。

$X(s) = \dfrac{1}{s+\alpha}$  |  ROC: $\operatorname{Re}(s) < -\alpha$（左半平面）

衰减系数 $\alpha$1.0
积分深度 $T$（$T<0$ 时积分区间落在 $t>0$，信号为 0）5.0

3D 模-相图（Z轴 = 幅值，颜色 = 相角）

红色竖线 = ROC 边界 $\sigma = -\alpha$，金色菱形 = 极点。注意：收敛区域在左侧（$\sigma<-\alpha$），和因果信号正好左右镜像！

反因果信号的核心结论

● 信号只存在于 $t<0$

$u(-t)$ 仅在 $t<0$ 时为 1，积分从 $-\infty$ 到 $0$。

● 收敛条件：$\sigma < -\alpha$

ROC 是极点左侧的左半平面，和因果信号正好相反。

● 和因果信号有相同的 $X(s)$！

变换结果都是 $\frac{1}{s+\alpha}$，但 ROC 完全相反。

● ROC 决定逆变换结果

同一个 $X(s)$，ROC 不同对应完全不同的时域信号。
