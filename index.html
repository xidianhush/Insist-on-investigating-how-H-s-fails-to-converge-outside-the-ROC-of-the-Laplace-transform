以 $x(t) = e^{-\alpha t} u(t)$ 为例  |  $X(s) = \dfrac{1}{s+\alpha}$  |  ROC: $\operatorname{Re}(s) > -\alpha$

积分上限 T5.0
衰减系数 α1.0

1. 3D 模-相图（Z轴 = 幅值，颜色 = 相角）

红色竖线 = ROC 边界 $\sigma = -\alpha$，金色菱形 = 极点。拖动 $T$ 滑块看曲面演化，鼠标可旋转 / 缩放 / 平移。

2. 复平面内三点对比：ROC 内 / 边界 $\sigma = -\alpha$ / ROC 外 — $|Z(s)|$ 随 $T$ 变化

3. ROC 边界振荡专题（$\sigma = -\alpha$）

$$|Z(s)| = \frac{2\left|\sin\left(\dfrac{\omega T}{2}\right)\right|}{|\omega|}$$ 振幅 $= \dfrac{2}{|\omega|}$，  周期 $= \dfrac{2\pi}{|\omega|}$，  永不收敛

4. 双边信号对比：$x(t) = e^{-a|t|}$（非因果，带状 ROC）

积分窗口右端点 $T_{\text{right}}$（左端点固定 $-30$） 0.0

两个极点 $s = \pm a$，ROC 为带状 $-a < \sigma < a$。 滑块从左拖到右：先只有负时间部分 $e^{at}$（要求 $\sigma < a$ 才收敛）， 再逐渐加入正时间部分 $e^{-at}$（要求 $\sigma > -a$ 才收敛）， 两者交集就是带状 ROC。两条红色竖线分别为 $\sigma = \pm a$。

核心结论

● 收敛 = 曲线贴平

ROC 内 $T$ 增大后 $|Z(s)|$ 趋于定值，极限存在，频域表示唯一确定。逆变换能还原出完整时域信号。

● 振荡 = 相位不收敛

边界上模不爆炸，但相位 $e^{-j\omega T}$ 持续旋转，极限不存在。逆变换得不到确定的时域信号。

● 发散 = 指数爆炸

ROC 外幅值随 T 指数增长，积分无意义。解析延拓后的函数值只是数学构造，不代表信号频谱。
