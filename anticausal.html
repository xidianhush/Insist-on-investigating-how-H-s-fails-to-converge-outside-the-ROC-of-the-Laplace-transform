拉普拉斯变换收敛域 (ROC) 可视化

反因果信号 $x(t) = -e^{-\alpha t} u(-t)$  |  $X(s) = \dfrac{1}{s+\alpha}$  |  ROC: $\operatorname{Re}(s) < -\alpha$（左半平面）

衰减系数 $\alpha$1.0
积分深度 $T$（区间 $[-T, 0]$，向左延伸） 5.0

3D 模-相图（Z轴 = 幅值，颜色 = 相角）

红色竖线 = ROC 边界 $\sigma = -\alpha$，金色菱形 = 极点 $s=-\alpha$。 注意：收敛区域在左侧（$\sigma<-\alpha$），和因果信号正好左右镜像！ 拖动 $T$ 增大时，左侧（ROC 内）曲面逐渐稳定收敛到 $\frac{1}{s+\alpha}$，右侧（ROC 外）指数爆炸。 鼠标可旋转 / 缩放 / 平移。

反因果信号的核心结论

● 信号只存在于 $t<0$

$u(-t)$ 是反因果阶跃函数，仅在 $t<0$ 时为 1。所以积分从 $-\infty$ 到 $0$，有限近似为 $[-T, 0]$，$T$ 越大向左延伸越远。

● 收敛条件：$\sigma < -\alpha$

积分中含 $e^{(\alpha+s)T}$ 项，当 $T\to\infty$ 时要求 $\alpha+\sigma<0$ 即 $\sigma<-\alpha$ 才收敛。ROC 是极点左侧的左半平面。

● 和因果信号有相同的 $X(s)$！

因果信号 $e^{-\alpha t}u(t)$ 和反因果信号 $-e^{-\alpha t}u(-t)$ 的变换结果都是 $\frac{1}{s+\alpha}$，但 ROC 完全相反（右半平面 vs 左半平面）。

● ROC 决定了逆变换的结果

同一个 $X(s)=\frac{1}{s+\alpha}$，ROC 不同对应完全不同的时域信号。这就是为什么"ROC 是拉普拉斯变换定义的一部分"——没有 ROC，$X(s)$ 不唯一对应任何时域信号。
